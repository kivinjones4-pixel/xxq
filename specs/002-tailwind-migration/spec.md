# Tailwind 样式迁移与 CR

- 状态：完成（样式迁移与前端 CR）
- 来源：用户 2026-09-09 要求“改成 tailwind，最后 cr”；基于 001 主要模块原型。
- 范围：将页面/组件自定义 CSS 迁移为 Tailwind 工具类，保留配色、布局、状态和三个页面交互；不修改后端合同、数据模型或依赖版本。

## 需求与验收

- R-01 / AC-01：布局、间距、字体、颜色、响应式和状态样式在 Vue 模板以 Tailwind 完整静态类表达；CSS 仅保留 Tailwind 入口、主题变量和基础重置，不以大量 @apply 替代迁移。
- R-02 / AC-02：桌面及 390px 窄屏下三个模块正常布局；导航高亮、在线/离线、选中/禁用、弹窗和表格样式保持正确，页面无整体横向溢出。Element Plus 样式覆盖限定于对应组件根节点。
- R-03 / AC-03：lint、类型检查、构建和既有测试通过，浏览器回归筛选、弹窗、模拟抄读和日志详情。
- R-04 / AC-04：依据 FE-01–FE-09 对最终差异及调用方完成 CR，记录发现、修复、证据和验证限制。

## 设计

沿用 Tailwind 4 和 Element Plus，保留主题变量及无 preflight 的基础重置。自有元素优先直接工具类，第三方组件内部元素使用根节点上的局部任意选择器。动态状态采用 aria/data 属性变体或完整静态类映射，不拼接 Tailwind 类名。

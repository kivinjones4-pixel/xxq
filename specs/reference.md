## 其他解释边界

- 11 §2.2 提到 D 搭配 Protocol，但 §2.1、§3.3、§4.1 明确 C 负责 Protocol；按详细分工由 C 负责、D/E 参与接口联调。
- 06/07 存在相互引用的章节跳转，但不能据此假定有未出现的类定义。
- 原文技术版本是项目约束，不是对当前软件版本的推荐。本次不升级技术栈。
- 协作指南统一为 `AGENTS.md`；`specs/`、单数 `task.md`、`skills/` 按用户要求保留；技能文件需要显式读取，本文档布局不宣称符合某版本 OpenSpec CLI 的目录规则。

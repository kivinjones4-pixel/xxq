- 状态：完成（仅交互原型，不代表真实业务功能完成）

- 依赖：000 前端初始化；沿用已锁定依赖，不安装新技术栈。

## 目标与范围

交付侧边导航、统一布局、电表档案、随时抄表、系统日志三个可交互原型。所有记录均为演示数据，修改仅在内存中保留，刷新恢复；全局持续标注原型模式。无后端调用、真实 LLS/GET、文件日志索引或业务持久化，不作为项目 T-12–T-14 完成证据。

## 需求与验收

### R-01 / AC-01 导航与目录
Given 启动前端；When 切换三个菜单、刷新 hash 路由或访问未知路由；Then 三个页面可达，当前菜单高亮，未知路由回电表档案。每页为 views/<page>/index.vue，私有 components/types 按需就近放置，目录约束写入 FE-01a。

### R-02 / AC-02 电表档案
Given 演示档案；When 搜索名称/表号、筛选类型/启用状态、翻页、重置；Then 表格及计数对应筛选，空结果明确显示。新增/编辑校验名称和唯一表号，查看详情、确认删除可交互；启用状态与在线状态分开。导出下载当前全部匹配数据 CSV；导入仅展示固定样例的校验预览与确认导入，不解析实际 Excel/CSV。

### R-03 / AC-03 随时抄表
Given 启用的演示电表和完整 dataItemId 字典；When 多表多项选择并开始演示；Then 空选择禁止开始，任务运行中禁用重复提交/改选，每表逐项推进、各表同时推进；可选择正常、超时、认证失败的演示场景，结果有等待/读取/成功/失败状态，失败无有效读数，0 值保留。离开页面清理定时器。该时间轴仅为界面模拟，不是 UCI 调度实现。

### R-04 / AC-04 系统日志
Given 静态演示日志；When 按时间（北京时间）、级别、服务和关键词筛选；Then 列表/计数一致，空结果明确；详情显示完整消息，导出当前全部匹配日志 CSV。无认证密码。

### R-05 / AC-05 工程与视觉
Given 现有锁文件；When lint、build（含类型检查）、test；Then 检查通过。浏览器验证三个页面及主要交互，窄屏导航和操作可达、表格局部横向滚动。只使用本地字体和代码图形。

## 设计与边界

- 浅色工作台、墨绿色侧边导航、青绿色强调色，内容区以筛选表单、表格和状态提示为主；不用业务无关的装饰图。
- 页面分别为 meter-assets、demand-read、system-logs；共享 AppShell、图标、指标组件；Pinia 管理跨页面演示档案，页面局部筛选/弹窗/日志/任务留在页面。
- 私有类型不作为正式 HTTP DTO；统一 API 模块保持原样。现有首页被档案首页替代，000 AC-02 首页文案证据不再适用；工程检查继续回归。
- 原型新增表单的名称/地址必填、去空格、唯一性、默认启用，以及固定样例部分导入、全部匹配 CSV 导出均为展示假设，Q-06 正式合同仍待决。不收集或缓存真实认证密码。
- 超时/认证失败场景作用于最后一个选中的电表；演示节拍固定，不定义生产超时和重试单位；Q-02/Q-04 仍待决。
- CSV 转义引号、逗号和换行，并防止单元格公式注入；临时下载 URL 用后释放。

2. 后端技术选型

2.1 BackEnd技术栈

技术 版本 选型理由
Spring Boot Spring Boot 现代化Java框架，自动配置，简化开发，内嵌服务器
MyBatis MyBatis Spring Boot Starter SQL映射框架，灵活的SQL编写，适合复杂查询
Maven Maven 3.x Java构建工具，依赖管理标准化
Java Java 1.8 Java运行环境，成熟稳定，生态完善

2.2 后端服务技术栈分配

Web BackEnd服务

  • 核心框架：Spring Boot
  • 数据访问：MyBatis Spring Boot Starter
  • API文档：Swagger或Knife4j

UCI服务

  • 核心框架：Spring Boot
  • 消息队列：MQBus.jar（自研组件）
  • 数据访问：MyBatis Spring Boot Starter（可选）

Channels服务

  • 核心框架：Spring Boot
  • TCP通信：Netty（高性能NIO网络框架，推荐）
  • 消息队列：MQBus.jar（自研组件）
  • 协议解析：Protocol.jar（自研组件，用于AARQ报文组装）

DLMS模拟表服务

  • 核心框架：Spring Boot
  • TCP通信：基于Spring Boot实现TCP客户端
  • 数据访问：MyBatis Spring Boot Starter（读取电表档案，用于身份识别和LLS认证验证）

2.3 后端技术栈特点

  • Spring Boot自动配置：减少XML配置，简化开发
  • 内嵌Tomcat服务器：打包为可执行JAR，简化部署
  • 统一的技术栈：所有BackEnd服务使用Spring Boot
  • MyBatis灵活SQL：适合复杂查询和数据操作

6. 自研组件技术选型

6.1 Channels服务（自研）

  • 开发方式：完全自研
  • 技术栈：Spring Boot + Netty + MQBus组件（自研） + Protocol组件（自研） + Maven
  • 部署方式：作为独立进程运行，通过MQBus消息队列与UCI服务通信
  • 核心功能：TCP/IP通信管理、AARQ认证（LLS）、MQBus消息转发、DLMS报文透明转发

Netty框架简介：

Netty是一个基于Java NIO的高性能异步事件驱动网络框架，具有以下特点：

特点 说明
异步非阻塞 基于NIO多路复用，少量线程处理大量TCP连接，适合电表高并发接入
事件驱动 通过事件回调机制处理网络事件（连接建立、数据读取、连接断开等）
管道（Pipeline）模式 通过ChannelPipeline组织报文编解码器，DLMS Wrapper解析和ASN.1解码可作为独立的Handler插入管道
成熟稳定 广泛用于Dubbo、RocketMQ等生产级框架

在Channels服务中的应用：

  • 作为TCP服务器监听端口，接收DLMS模拟表和真实电表的TCP连接
  • 通过ChannelPipeline处理DLMS Wrapper报文解析
  • 管理电表地址与TCP连接的映射关系
  • 处理登录、心跳、AARQ/AARE、GET请求/响应等报文转发

6.2 MQBus组件（自研）

  • 开发方式：完全自研
  • 技术栈：ActiveMQ + JMS API
  • 集成方式：作为Common模块的一部分，引入到UCI服务和Channels服务
  • 核心功能：消息队列连接管理、消息发送和接收、MQMessage消息封装

6.3 其他Common组件（自研）

Protocol组件、Logger组件、LoggerQuery组件均为自研，详细设计详见《06-Common模块开发指导》。

9. Maven项目结构规范

9.1 Maven项目结构要求

  • 所有BackEnd服务都必须使用Maven项目结构
  • 每个BackEnd服务都是独立的Maven项目
  • 遵循Maven标准目录结构

9.2 Maven标准目录结构 

项目根目录/
├── pom.xml                  # Maven配置文件（必须）
├── src/
│   ├── main/
│   │   ├── java/           # Java源代码目录
│   │   │   └─ 包名/
│   │   │       └─ 模块代码
│   │   └── resources/      # 资源文件目录
│   │       ├── application.yml/properties  # Spring Boot配置文件
│   │       ├── mapper/     # MyBatis Mapper XML文件
│   │       └─ 其他资源文件
│   └── test/
│       ├── java/           # 测试代码目录
│       └── resources/      # 测试资源目录
└── target/                 # 编译输出目录（自动生成）

9.3 必须存在的文件

  • pom.xml：Maven项目配置文件（每个服务必须）
  • src/main/java/：Java源代码目录
  • src/main/resources/：资源文件目录
  • application.yml或application.properties：Spring Boot配置文件

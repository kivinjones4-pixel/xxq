Common模块开发指导

1. Common模块概述

Common模块是HES系统的公共组件模块，提供基础设施功能供各服务使用。所有组件均为自研。

1.1 必需组件（需要自研） 

Common模块结构（必需组件）
├── MQBus组件 - 消息队列通信组件（封装ActiveMQ）
├── Protocol组件 - DLMS协议解析组件（核心业务组件）
├── Logger组件 - 分布式日志记录组件（基于Lucene）
└── LoggerQuery组件 - 日志查询组件（配合Logger使用）

2. MQBus组件架构指导

2.1 MQBus组件定位

MQBus组件提供消息队列通信功能，封装ActiveMQ的操作，用于服务间的异步消息通信。

2.2 MQMessage消息设计

MQMessage是消息载体，核心字段包括：

字段 说明
priorityLevel 消息优先级
fromId/fromType 发送方ID和服务类型
toId/toType 接收方ID和服务类型
messageId 消息唯一ID
messageType 消息类型（ReadTask、ReadResult、StatusReport）
payload 业务数据载体

2.3 随时抄表任务消息载体

随时抄表场景中，payload应包含以下信息：

字段 说明
meters 电表列表（包含meterId、meterAddress）
dataItems 数据项列表（包含dataItemId、obisCode、classId、attributeId）
authPassword LLS认证密码（由UCI从电表档案读取，传递给Channels用于AARQ组装）
dlmsMessage DLMS GET请求报文（由UCI组织，ASN.1编码）

重要说明：

  • meterAddress（电表地址）：电表的唯一标识符，用于电表身份识别
  • Channels服务根据电表地址查找对应的TCP连接，发送DLMS报文

2.4 随时抄表场景应用说明

在随时抄表场景中，MQBus组件用于UCI服务和Channels服务之间的消息传递：

消息流向：

  • UCI服务 → MQBus → Channels服务：发送抄读任务消息（包含电表地址、LLS认证密码、DLMS报文）
  • Channels服务 → MQBus → UCI服务：返回抄读结果消息（包含电表地址、DLMS响应）

详细流程说明：
随时抄表的完整业务流程（包含登录、心跳、AARQ/AARE、GET请求等）详见：

  • 协议流程：《07-DLMS-COSEM协议实现指导》第5.1节"随时抄表协议流程"
  • 系统架构：《02-系统架构设计》第4节"数据流向"
  • 模拟表服务：《08-DLMS模拟表服务设计》第4.1节"TCP客户端通信流程"

3. Protocol组件架构指导

3.1 Protocol组件定位

Protocol组件提供DLMS协议解析功能，用于UCI服务、Channels服务和DLMS模拟表服务的DLMS报文编解码。

3.2 协议实现参考

Protocol组件的DLMS协议核心结构（COSEM对象标识、AARQ/AARE应用连接含LLS认证、GET请求/响应结构）、ASN.1编解码要点、常用OBIS码列表等详细内容，详见《07-DLMS-COSEM协议实现指导》第2节"协议核心组件"和第3节"DLMS/COSEM报文结构"。

4. Logger组件架构指导

4.1 Logger组件定位

Logger组件提供分布式日志记录功能，基于Lucene实现，用于系统日志和业务日志的存储。

4.2 Logger设计要点

  • 基于Lucene的日志索引和存储
  • 文件日志输出
  • 控制台日志输出
  • 日志级别管理（info、warn、error、debug）
  • 分布式日志收集

5. LoggerQuery组件架构指导

5.1 LoggerQuery组件定位

LoggerQuery组件提供日志查询功能，配合Logger组件使用，支持高效的日志检索。

5.2 LoggerQuery设计要点

  • 基于Lucene的日志索引查询
  • 时间范围查询
  • 日志级别筛选
  • 关键词搜索
  • 分页查询支持

6. Common模块开发要点

6.1 架构原则

  • 单例模式：MQBus、ProtocolModule等核心类使用单例模式
  • 接口抽象：LoggerAppender、ProtocolModule等使用接口抽象
  • 序列化支持：MQMessage等消息类需实现Serializable接口
  • 线程安全：消息队列使用BlockingQueue保证线程安全

6.2 开发约束

  • 根据项目实际需求简化或调整设计
  • 保持组件的独立性和可复用性

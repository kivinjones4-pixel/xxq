API接口规范

1. API接口总体设计

1.1 API接口风格

  • 接口风格：RESTful API
  • 数据格式：JSON
  • 编码格式：UTF-8

1.2 API接口路径规范

  • 路径格式：POST /module/action
  • 示例：POST /meter/list、POST /meter/save

1.3 API接口版本管理

  • 版本号：v1
  • 路径示例：POST /api/v1/meter/list

2. 统一返回结果格式

2.1 成功返回格式 

{
  "code": 200,
  "message": "success",
  "data": {
    // 返回数据
  }
}

2.2 失败返回格式 

{
  "code": 500,
  "message": "错误信息",
  "data": null
}

2.3 分页返回格式 

{
  "code": 200,
  "message": "success",
  "data": {
    "total": 100,
    "list": [
      // 数据列表
    ]
  }
}

3. 电表档案管理API

3.1 电表列表查询

  • 接口路径：POST /api/v1/meter/list
  • 请求参数：需要支持分页、电表名称搜索、状态筛选
  • 返回结果：返回电表列表，包含电表基本信息

3.2 电表详情查询

  • 接口路径：POST /api/v1/meter/detail
  • 请求参数：电表ID
  • 返回结果：返回电表详细信息，包含电表基本信息

3.3 电表新增

  • 接口路径：POST /api/v1/meter/save
  • 请求参数：包含电表地址、电表名称、电表类型、协议类型、通信方式、认证密码、状态等
  • 返回结果：返回新增电表的ID

3.4 电表修改

  • 接口路径：POST /api/v1/meter/update
  • 请求参数：包含电表ID和需要修改的字段

3.5 电表删除

  • 接口路径：POST /api/v1/meter/delete
  • 请求参数：电表ID

3.6 批量导入

  • 接口路径：POST /api/v1/meter/import
  • 请求参数：上传Excel/CSV文件
  • 返回结果：返回导入成功数、失败数及失败明细
  • 业务说明：支持Excel/CSV格式导入，对重复电表地址、格式错误等做校验并返回错误提示

3.7 批量导出

  • 接口路径：POST /api/v1/meter/export
  • 请求参数：同3.1节查询条件（按当前查询结果导出）
  • 返回结果：返回Excel/CSV文件流

4. 随时抄表API

4.1 获取电表档案列表

  • 接口路径：POST /api/v1/meter/list（同3.1节电表列表查询）
  • 业务说明：用于前端展示可选择的电表列表，用户可勾选要抄读的电表

4.2 获取数据项列表

  • 接口路径：POST /api/v1/dataItem/list
  • 请求参数：从字典表（dict_data_item）查询，支持分页、数据项名称搜索
  • 返回结果：返回数据项列表，包含数据项ID、数据项名称、OBIS码等字段
  • 业务说明：用于前端展示可选择的随时抄表数据项，用户可勾选要抄读的数据项

4.3 提交随时抄表任务

  • 接口路径：POST /api/v1/demandRead/start
  • 请求参数：包含电表ID列表、数据项ID列表（OBIS码）、超时时间、重试次数
  • 返回结果：返回任务ID
  • 业务流程：详见《07-DLMS-COSEM协议实现指导》第5.1节"随时抄表协议流程"

任务分解规则：

  • 前端可同时选择多个电表和多个数据项，所选电表均需抄读所选数据项
  • UCI将请求按电表维度分解为独立任务：一个电表一个抄读任务
  • 同一电表任务内，多个数据项串行执行（上一个数据项抄读完成后才能抄读下一个）
  • 不同电表的任务并行执行

重要说明：

  • 随时抄表功能实时展示抄读数据
  • 抄读结果实时返回给前端展示

5. 日志查询API

5.1 系统日志查询

  • 接口路径：POST /api/v1/log/sys/list
  • 请求参数：需要支持分页、时间范围、日志级别、关键词搜索
  • 返回结果：返回系统日志列表
  • 存储方式：系统日志基于文件存储（Logger组件）

5.2 日志详情查询

  • 接口路径：POST /api/v1/log/sys/detail
  • 请求参数：日志ID
  • 返回结果：返回单条日志完整内容

5.3 日志导出

  • 接口路径：POST /api/v1/log/sys/export
  • 请求参数：同5.1节查询条件（按当前查询结果导出）
  • 返回结果：返回Excel/CSV文件流

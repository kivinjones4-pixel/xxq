# HES 验收检查表

需求详情见 [业务规范](../../../specs/spec.md)，未明确策略见 [待决清单](../../../specs/reference.md)。本表是检查导航，不复制全部规范。

| 范围 | 关键场景 | 证据 |
| --- | --- | --- |
| ARCH/DELIVERY | 六模块，四独立服务；按 MySQL→MQ→Channels→模拟表→UCI→Web BackEnd→前端启动 | 进程/端口、构建与启动记录 |
| METER/DATA/API | 新增 ID、修改/删除、组合筛选、重复地址、同 OBIS 不同属性、导入错误、条件导出 | API 请求响应、SQL 约束、页面结果 |
| CONN | 客户端主动登录；0x01/0x81、0x02/0x82；3 分钟心跳、超过 9 分钟离线；重连清理 | 带时间的连接日志或报文 |
| AUTH/PROTO | 正确密码成功；错误密码无 GET；固定报文样本、半包/多帧/异常数据 | 样本依据、断言、脱敏轨迹 |
| READ/MQ | 两表三项、同任务串行/跨表并行、MQ 往返与匹配、失败/迟到/重复响应 | taskId/messageId/invokeId 关联轨迹 |
| SIM | 多表独立连接、类型与缩放、累计值与时间值 | 可复现配置与返回数据 |
| LOG | 文件/Lucene 写入，时间/级别/关键词、分页、详情、导出 | 日志样本、查询和下载结果 |
| E2E | 页面发起后经四服务与模拟表返回真实链路数据 | 关联全过程与页面结果 |

用可控时钟测试超时边界；实际运行验收仍需说明使用的配置，不将缩短的测试心跳间隔当成默认值。协议共享组件自测通过不等于外部标准符合，应说明独立参考验证是否完成。

任务书质量要求：核心组件和核心服务单元测试覆盖率至少 60%，提交统计范围。最终评分参见原文 00 §10：通过线 70；模拟表成功抄读与系统运行联调为否决项；核心功能和协议低分另有降级规则，不能只按总分判断。
